# orders

Микросервис для заказов

## Как запустить

```bash
docker compose up --build # запустить бд
go run ./cmd/service/main.go 
```

## Для разработки
Установи mise для удобной работы c инструментами

```bash
curl https://mise.run | sh
mise install
```
